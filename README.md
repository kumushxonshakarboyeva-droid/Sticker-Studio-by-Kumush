# Vid2Sticker Bot

Telegram bot for converting:

- Video → WEBM sticker
- GIF → WEBM sticker
- Photo → WEBP sticker

## Features

- Admin unlimited
- Users: 5 stickers per day
- Automatic daily reset
- SQLite database
- Sticker packs
- Chroma key
- FFmpeg
- Render/Docker support

## Environment Variables

BOT_TOKEN=your_bot_token
ADMIN_ID=your_telegram_id

Optional:

DAILY_STICKER_LIMIT=5
MAX_FILE_MB=50
